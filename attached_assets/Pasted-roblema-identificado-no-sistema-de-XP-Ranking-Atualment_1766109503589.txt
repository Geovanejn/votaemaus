roblema identificado no sistema de XP / Ranking

Atualmente, o sistema de XP funciona corretamente no frontend e durante a lição:

await fetch('/api/study/xp/deduct', {
  body: JSON.stringify({ amount: 10, reason: 'wrong_answer', lessonId })
});

// Usar dica deduz 5 XP
await fetch('/api/study/xp/deduct', {
  body: JSON.stringify({ amount: 5, reason: 'hint', lessonId })
});


Essas deduções:

aparecem corretamente para o usuário

alteram o XP durante a lição

❌ Porém, no envio da lição concluída para o ranking (geral, por ano e por revista), essas deduções NÃO estão sendo consideradas.

🧨 Causa raiz do problema

Os rankings estão sendo calculados com base em XP teórico, normalmente algo como:

xp = correctAnswers * 20


Ou seja:

apenas respostas corretas entram no cálculo

erros (-10 XP) e dicas (-5 XP) são ignorados

o ranking recalcula o XP do zero

📌 Resultado prático:

O XP exibido durante a lição ≠ XP persistido no ranking

📉 Exemplo real do erro

Lição com 5 perguntas:

4 acertos → 4 × 20 = 80 XP

1 dica usada → -5 XP

1 erro → -10 XP

XP correto esperado:
👉 65 XP

XP enviado ao ranking atualmente:
❌ 80 XP

Isso afeta:

Ranking geral

Ranking por ano

Ranking por revista

✅ Solução MAIS ROBUSTA (recomendada)
🔒 Backend como fonte única da verdade

O XP não deve ser recalculado no momento de salvar o ranking.

Toda alteração de XP já ocorre via eventos explícitos:

resposta correta → +20

erro → -10

dica → -5

Esses eventos já passam pelo backend (/xp/add e /xp/deduct).

✔️ Regra principal

O ranking deve usar o XP final já acumulado da lição, e não recalcular nada.

🧩 Implementação sugerida (TypeScript)
1️⃣ Persistir XP por lição no backend

Exemplo de estrutura:

interface LessonXp {
  userId: string;
  lessonId: string;
  xp: number;
}


Toda ação atualiza esse valor:

lessonXp.xp += amount; // positivo ou negativo

2️⃣ Finalização da lição

Endpoint de conclusão:

POST /api/study/lesson/complete


Backend:

const lessonXp = await getLessonXp(userId, lessonId);

// XP já está correto, com bônus e penalidades
const xpFinal = lessonXp.xp;

3️⃣ Atualizar rankings (SEM RECÁLCULO)
await updateGlobalRanking(userId, xpFinal);
await updateYearRanking(userId, year, xpFinal);
await updateMagazineRanking(userId, magazineId, xpFinal);


🚫 Nunca usar:

correctAnswers * 20

🧠 Por que essa solução é a correta?

Evita divergência entre UI e ranking

Impede manipulação do frontend

Centraliza a lógica no backend

Funciona para qualquer regra futura (bônus, multiplicadores, eventos especiais)

Mantém ranking geral / anual / revista consistentes

⚠️ Observação importante

Se for necessário auditar no futuro, pode-se manter um log de eventos:

{ type: 'correct' | 'wrong' | 'hint', xp: number }


Mas o ranking sempre usa o total acumulado.

✅ Resumo final (em uma frase)

O problema ocorre porque o ranking recalcula o XP ignorando deduções; a solução robusta é fazer o backend acumular o XP real da lição e enviar esse valor final diretamente para todos os rankings, sem qualquer recálculo.
